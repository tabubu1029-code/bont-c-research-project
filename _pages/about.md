## 歡迎來到我的研究計畫網頁！
本計畫致力於針對肉毒桿菌毒素 C 型 (BoNT/C)，我們透過結構生物資訊學的方法，設計並改良可用於治療禽類之單株抗體。
[![DOI](https://zenodo.org/badge/1311596237.svg)](https://doi.org/10.5281/zenodo.21557162)

## 研究目標
1. 利用生物資訊學的方式來將過去已用於治療或是發表的單株抗體、疫苗，根據 C 型毒素的結構以及特性進一步進行改造，並增強其實用性。
2. 建立 C 型毒素的結構資料庫，增加對於 C 型以及其嵌合體毒素之結構解析。
3. 嘗試將可以中和 C 型毒素的單株抗體套用至其他嵌合體毒素。
4. 將中和不同點位之單株抗體綜合在一起形成寡株抗體並實測效力。

## 核心研究步驟
1. **結構標記**：將 C 型毒素的受體結合區標記出來並進行命名與編號。
2. **結合機轉**：詳細記錄各個口袋的機轉。
3. **口袋特性解析**：針對每個已編號的口袋進行特性解析（包含疏親水性、極性、空間大小、帶電性）。
4. **抗體配對與篩選**：找尋其他亞型（如 A、B、D 型等）的已知抗體，找出在結構上有機會與 C type 進行中和的潛力抗體。
5. **結構改寫與模擬**：利用計算工具 (AlphaFlod)，改寫抗體的特性使其符合毒素結合點特性。
6. **對接與評分**：將改寫完成的抗體和毒素利用 HADDOCK 進行模擬接合，並記錄結合分數。
